# 팬텀하이브 백작 메이커 콘텐츠 편집기

## 웹에서 열기

[팬텀하이브 웹 편집기](https://jnscee.github.io/phantomhive-maker/editor/)를 브라우저에서 엽니다. 프로그램 설치 없이 공개 게임 버전을 불러옵니다.

1. 콘텐츠를 수정하고 **게임에서 미리보기**로 확인합니다. 미리보기는 플레이 중인 저장 데이터와 분리됩니다.
2. **브라우저에 저장**을 누릅니다. 같은 브라우저에서 다시 열면 저장한 편집을 이어갈 수 있습니다.
3. **파일 관리**에서 변경 파일 ZIP이나 수정이 반영된 전체 게임 ZIP을 내려받습니다.

새 버전이 공개되면 편집기는 최신 게임으로 시작합니다. 이전 버전의 수정본은 **파일 관리 → 이전 버전 변경 ZIP**으로 내려받을 수 있습니다. 공개판을 업데이트하기 전 작업은 변경 ZIP으로 따로 보관해 두세요.

## Windows 프로그램으로 열기

1. 저장소 전체를 ZIP으로 내려받아 압축을 풉니다. `current` 폴더와 루트의 `game-part-*.zip` 파일이 필요합니다.
2. [Node.js 22 이상](https://nodejs.org/)과 [Python 3](https://www.python.org/downloads/windows/)을 설치합니다. Python 설치 중 Windows용 `py` 실행기를 포함합니다.
3. `tools/content-editor/Start-Editor.cmd`를 더블클릭합니다. 첫 실행에서 편집기에 필요한 패키지를 설치한 뒤 [편집기](http://127.0.0.1:4179/)를 엽니다. 편집 중에는 열린 명령 창을 유지합니다.

## 콘텐츠 수정

- **스토리**에서 프롤로그, 엔딩, 모든 사용인 영입 장면의 화자와 대사를 편집합니다. 대사마다 추가, 삭제, 순서 이동이 가능합니다.
- **이벤트**에서 생일, 기존 월말 사건, 수업 사건, 실기, 계절 행사, 런던 박람회, 방문 대화, 타운하우스 업무 기록을 편집합니다. 기존 월말 사건의 시작 월과 활동 사건의 필요 횟수를 조정할 수 있습니다. **＋ 이벤트**로 35개월 본편의 지정 월에 한 번 발생하는 새 이야기를 추가합니다. 월말 이벤트를 저장한 뒤 **선택지 → ＋ 선택지 추가**에서 버튼 문구, 응답과 능력치 변화를 추가합니다. 월말·수업 사건과 자유행동 방문 사건도 추가 선택지를 지원합니다.
- **기타 대사**에서 튜토리얼, 수업 강평, 방문이나 상점에서 쓰는 문구를 편집합니다.
- **BGM · SE**에서 트랙을 재생하고 기존 트랙이나 클릭 효과음 파일을 바꿉니다. 이벤트나 엔딩에 사용할 BGM은 해당 이야기에서 선택합니다. **CG · 이미지**에서는 CG, 배경, 스탠딩, 동작 프레임을 확인하고 원본 파일을 교체합니다. 같은 파일을 쓰는 장면에는 교체가 함께 반영됩니다. 기존 리소스와 같은 형식으로 파일당 20 MB까지 교체할 수 있습니다.
- **화면 효과**에서는 일정 재생 장면별 배경, 동작 패턴, 효과 및 지문을 고릅니다.

## GitHub 토큰 저장

**토큰 관리**에서 GitHub Fine-grained 토큰과 별도로 정한 잠금 비밀번호(12자 이상)를 입력하고 **이 브라우저에 저장**을 누릅니다. 입력한 토큰은 암호화되어 같은 브라우저에 남습니다. 편집기를 새로 열면 잠금 비밀번호를 입력해 잠금을 해제합니다. 같은 페이지를 열어 둔 동안에는 여러 번 업로드할 수 있습니다. 업로드 창에서 **저장하고 업로드**를 사용해도 저장됩니다. **저장한 토큰 삭제**는 이 브라우저의 저장본을 지웁니다.

## 대사별 연출

프롤로그, 영입, 엔딩 및 추가한 월말 스토리의 대사 아래 **대사 연출**을 펼칩니다. 페이드와 흔들림, 대사별 CG·BGM·효과음을 지정하고 **게임에서 미리보기**로 확인할 수 있습니다. CG와 BGM을 지정하면 해당 대사에 적용되며, 다음 대사에는 다음 대사의 설정이나 장면 기본값이 적용됩니다. 자동 재생 장면에서는 대기 시간을 더할 수 있습니다. 스탠딩은 모든 지원 장면에서 대사별로 왼쪽과 오른쪽을 지정하거나 숨길 수 있습니다. 두 위치를 미지정으로 두면 장면의 기본 배치를 사용합니다. 화자 칸을 비우면 이름표가 숨겨집니다. 이벤트에서 추가한 선택지에는 **선택지 후속 장면**으로 별도의 대사와 연출을 넣을 수 있습니다.

## 스토리 장면 추가

**스토리 → ＋ 스토리 추가**에서 프롤로그 장면, 영입 장면 또는 월말 스토리 이벤트를 고릅니다. 프롤로그·영입 장면은 선택한 이야기의 마지막에 붙습니다. 장면 제목과 대사 한 줄 이상을 입력하고 저장하면 새 장면이 열립니다. 프롤로그에는 CG와 BGM을, 영입 장면에는 배경과 스탠딩도 지정할 수 있습니다.

## 새 콘텐츠 등록

1. **＋ 콘텐츠 추가**에서 스탠딩, CG, 배경, BGM, 파티클 효과, 월말 이벤트, 영입 장면을 고릅니다. 파일 ID는 자동으로 채워집니다.
2. 이미지와 음원은 파일당 20 MB까지 올릴 수 있습니다. 스탠딩과 배경은 WebP, PNG, JPEG를, CG는 WebP를, BGM은 MP3, Ogg, WAV를 사용할 수 있습니다.
3. 영입·월말 장면의 **이미지 · 소리** 탭에서 등록한 파일을 고릅니다. 엔딩 CG는 **대사** 탭에서 대사별로 연결합니다. 파티클 효과는 **화면 효과**에서 일정 재생에 연결합니다.

## 테스트하고 게임에 반영하기

1. 편집할 항목을 고른 뒤 **게임에서 미리보기**를 누릅니다. 장면이 지정된 항목은 해당 장면부터 시작합니다. 음악은 미리보기 게임 화면을 클릭하면 재생됩니다. 미리보기 회차는 기존 저장에 영향을 주지 않습니다.
2. **게임 파일에 적용**을 누르면 `current`의 게임 원본을 저장합니다. 적용 직전 파일은 `.editor-backups`에 보관됩니다. 편집기를 열어 둔 동안 **마지막 적용 되돌리기**로 직전 저장을 취소할 수 있습니다.
3. **게임 ZIP 받기**를 누르면 저장한 내용이 포함된 전체 게임 빌드를 내려받습니다. ZIP의 최상단에 `index.html`이 있습니다. 편집기 밖에서 새로 빌드할 때는 `current/build.py`를 사용하세요.

## 공개 게임 업데이트

웹 편집기에서 **브라우저에 저장 → GitHub에 업로드**를 누르면 저장한 대사와 새로 추가하거나 교체한 리소스가 하나의 커밋으로 반영됩니다. GitHub에서 [Fine-grained 토큰](https://github.com/settings/personal-access-tokens/new)을 만든 뒤 저장소를 `jnscee/phantomhive-maker`로 제한하고 **Contents → Read and write**를 선택합니다. 토큰은 업로드 창에 입력하고 **공개 게임에 반영**을 누릅니다. 저장한 토큰이 있다면 잠금을 해제해 재사용할 수 있습니다. 업로드 후 **배포 확인**에서 GitHub Pages의 진행 상태를 확인할 수 있습니다.

ZIP으로 수동 반영하려면 **변경 파일 ZIP**을 풀고 `current` 아래 파일을 [GitHub 저장소의 current 폴더](https://github.com/jnscee/phantomhive-maker/upload/main/current)에 같은 경로로 업로드합니다. 대사는 해당 JavaScript 파일을, 이미지나 음원은 `assets` 폴더 안의 경로를 유지합니다. GitHub에서 변경 사항을 커밋하고 `main`에 반영하면 GitHub Pages가 자동으로 게시합니다.

Windows 편집기에서는 **게임 파일에 적용**으로 저장한 `current/` 변경 사항을 GitHub에 커밋합니다. 기존 ChatGPT Sites 주소는 같은 빌드를 별도로 게시합니다.
